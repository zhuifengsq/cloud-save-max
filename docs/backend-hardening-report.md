## 兼容与限制

- 单uvicorn进程、单副本、4个执行槽不变；409/429仍在SSE建立前返回。
- preview不写执行历史，手动执行不受运行星期限制，pending不当死链，手动引流不接入自动转存。
- 原 RunTaskUseCase.run 仅作存量兼容/灰度参数测试，生产走 execute 分阶段入口。use_unified_run_use_case=False 不再把生产切回旧的不安全事务流程；后续移除该过渡开关须单独评估。
- 无真实网盘账号/Telegram联调，无远端CI运行或部署。契约/假网络测试通过不代表所有网盘当前线上API均已实测。
- 不提供崩溃恢复、持久化队列、跨进程锁或跨网盘/数据库原子事务。结果不明不在同次调用重放；未来独立运行仍需要网盘侧事实核对，不能据此宣称端到端恰好一次。
- 后端先部署、新前端后部署；回退反序。跨模块用例/装配/契约作为一个集成批次回退，不能只回退单个调用方。
