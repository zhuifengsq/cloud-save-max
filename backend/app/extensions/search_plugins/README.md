# Python 搜索插件

管理员可在“搜索插件”页面上传 `<key>_plugin.py`，也可以将文件放到本目录后刷新列表。
插件必须定义一个继承 `BaseSearchPlugin` 的类，`key` 与文件名的 `<key>` 一致，
`search(keyword)` 返回字典列表，包含标题 `taskname`（或 `title`）及网盘分享链接
`shareurl`（或 `url`）。可选字段为 `datetime` 和 `content`。

见 `examples/sample_plugin.py`。上传的 Python 文件会在服务器上运行，因此只有
管理员可以上传、启停和测试插件。插件中的网络请求应设置超时。

内置的 `quark4k_plugin.py` 已适配自 pan-relay 的 Quark4K 搜索逻辑。它会查询
Quark4K 公开讨论的前两页，并提取当前项目支持的网盘分享链接。新插件默认关闭；
在“搜索源管理 → Python 搜索插件”中启用后即可参与追剧任务搜索。

## WPS 文档搜索

内置 `wps_plugin.py` 使用已有的 `requests` 匿名读取公开 WPS 文档，无需浏览器、
登录账号或额外服务。更新后可直接在 Python 搜索插件列表中找到，无需手动上传。

- 点击“配置”，填写 `https://www.kdocs.cn/l/...` 文档链接，默认预填“热门剧”文档。
- 网盘类型支持多选夸克、百度、迅雷，至少选择一项；默认全选。
- 启用后参与正常搜索及自动换链；任务搜索还会按目标网盘继续筛选。
- 首次搜索获取全文并按段落关联标题、链接、提取码；文档标注的集数仅作为资源描述。
- 文档缓存有效期 15 分钟，过期后由下一次搜索更新，无后台定时下载。
- “清除缓存”同时清除该文档缓存和聚合搜索结果缓存，下次搜索重新读取。
- 缓存在服务进程内，最多保留 16 份文档索引，重启后重新建立；多进程部署时每个进程
  独立缓存，清除操作作用于处理请求的进程（与现有聚合搜索缓存一致）。
- 只支持无需登录或密码的公开文字文档；读取失败会报告错误，不缓存空结果。
  WPS 网页接口若变化，可能需要更新读取适配。
